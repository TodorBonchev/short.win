title: Normal curve quotes use the original mint supply
file: crates/shortwin-math/src/fees.rs:164
related_locations: crates/shortwin-math/src/fees.rs:44-51,178-185; programs/shortwin/src/venues/pump_curve.rs:425-483; crates/shortwin-math/src/quote/pricing.rs:139-144; crates/shortwin-venue-state/src/pump.rs:695-730
seam: boundary×invariant; the supply basis selects a piecewise fee tier and differs between the ordinary and synthetic paths.
code_smells: The normal curve fee uses a fixed supply; the synthetic fee uses the live supply; the reader accepts multiple fee tiers.
description: A token holder gets inaccurate curve quotes after a burn if Pump adds fee tiers; the source says its current single tier prevents this.
path: Conditional future schedule with distinct tiers → holder burns circulating tokens → normal quote selects the tier at the original supply → its execution and risk costs use a different fee from the venue.
proof: The source explicitly says the deployed curve uses the live mint supply. `pump_curve` instead calls `curve_fees_at(vt, vq, PUMP_CURVE_MCAP_SUPPLY, s)`, where the constant is 1,000,000,000,000,000. The production adapter calls this resolver for `fees` and the EMA fee. It calls `pump_curve_at_supply` only for `CurveStage::Live.synthetic_fees`. `CurvePricing::buy` dispatches to `curve_synthetic`, whose `q <= rT` branch uses the normal `curve_fees`.
numeric_proof: Use a standard-offset live curve with vT = 400,000,000,000,000, vQ = 80,475,000,000, rT = 120,100,000,000,000 and rQ = 50,475,000,000. After a holder burns 100,000,000,000,000 circulating units, live supply is 900,000,000,000,000. The fixed-supply market cap is 201,187,500,000 lamports; the live-supply cap is 181,068,750,000. A hypothetical schedule with protocol fees of 100 bps from threshold 0 and 50 bps from threshold 190,000,000,000 selects different tiers. Set LP and creator fees to zero. For q = 1,000,000,000,000, q <= rT, and the conservative net is ceil(q*vQ/(vT-q))+1 = 201,691,731. The normal quote costs 202,700,190 lamports at 50 bps. The same formula at the live-supply tier costs 203,708,649, a difference of 1,008,459 lamports. Integer arithmetic checked this calculation; no protocol code ran.
guards_and_limits: The documented deployed curve schedule has one tier at threshold zero. That schedule makes both resolutions equal today. No real multi-tier curve schedule was established in this static pass. Account ownership and discriminator checks prevent a caller from supplying the hypothetical schedule directly. This is not a confirmed production exploit.
impact_if_activated: Quotes can understate or overstate ordinary curve execution costs, margin, fee-scaled caps, and risk costs after a supply burn crosses a fee threshold.
fix: Use the live mint supply for all curve fee tiers and the EMA fee view.
validation: Static source trace and pure integer arithmetic only; no build, test, simulation, or runtime reproduction.
