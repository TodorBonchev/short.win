## RFQ log

The owner books the audit (M10 plan, Q2). These are the plan's recommendations; the owner has
not decided any of them:
- send RFQs to 3–4 Solana-native firms now, because public queues are 4–12 weeks;
- one full private audit;
- then a contest (Sherlock or Cantina) on the fixed code;
- then a bug bounty (Immunefi) at M11.

The plan quotes ≈ $150–300k for the primary audit and $50–150k for a contest or second
review. These are the researchers' market figures and are **not verified**.

### What each RFQ carries

1. The one-page summary (AUDIT.md §1) and the scope (AUDIT.md §2 table, `scope.txt`):
   - on-chain core: 106 Rust files, ≈ 21.1k non-test nLOC (29.9k tokei code);
   - optional keeper: 26 files, ≈ 10.5k, or its core subset of ≈ 4.7k.
2. The stack: Anchor 1.2.0, Agave 4.1.2, SBPF v3. The CPI targets: pump.fun, PumpSwap,
   pump-fees, Raydium AMM v4 and CPMM, Token / Token-2022, memo.
3. The code freeze date and the requested window. TODO(owner, Q2).
4. Repository access. The repository is private (owner question Q3): access by invitation,
   or a snapshot of the tag.
5. What the quote should state:
   - price;
   - earliest start;
   - duration in engineer-weeks and the number of auditors;
   - method: manual review, fuzzing, formal methods (Certora for `shortwin-math`);
   - fix-review terms;
   - whether the report may be published;
   - whether the keeper subset changes the quote.
